## Predicción de contratación de depósito a plazo con un MLP

**Estudiante:** Tomás Benjamín Suárez Alvarado  
**Asignatura:** DLY0100 — Deep Learning

### Descripción
Implementación de un Perceptrón Multicapa (MLP) utilizando TensorFlow/Keras para predecir la contratación de depósitos bancarios utilizando el dataset Bank Marketing. Incluye preprocesamiento con scikit-learn, experimentación controlada de hiperparámetros, manejo de desbalance de clases y evaluación con métricas de rendimiento.
